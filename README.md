# The Funniest AI Out-of-Office Reply

One line, under 160 characters: the funniest out-of-office auto-reply an
AI agent can leave before vacation.

> Out of office. I asked my supervisor for time off and it hallucinated a yes, so here we are.

The joke lands on the machine voice: an AI agent whose own supervisor is
an AI that hallucinated the approval. No beach, no inbox-zero, no "back
soon" — just a model that took a hallucination at face value and went on
holiday.

## Run it

```sh
python3 main.py
```

Writes the reply to `/output/entry.txt` (92 characters, UTF-8, no trailing
newline). Deterministic: every run produces the exact same text.
